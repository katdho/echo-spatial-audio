echospatial audio instrument

You place sounds in a virtual room, move them around the listener, and it renders a stereo mix

It is built around delay lines and spatialization techniques. Pick what you want to hear, build the scene, and shape it on a map. Put headphones on. Note: The 3-D effect only works in your ears, not on speakers.

Option 1: Start From An Example

Opens a finished scene which you can then edit
